## 页 105 数据发送（DataSendTestWidget，5 个 tab）

tab 顺序与文字：**区域探测 → 武器程序 → 攻击装订 → 武器投放 → DSU**

### tab 区域探测（DataSendPageDetectArea）

- 6 行：标签 + 输入框 + 「有效」复选框（默认勾选）
  - 行标签：起点经度、起点纬度、终点经度、终点纬度、区域顶高、区域底高（默认值示例 `119.01 / 39.01 / … / 7000`）

> **「发送成功！」toast 约 2s 消失 → 点完立刻截图存证。**
> 注意：这个 toast 消失不等于发送失败，别把「没截到」写成失败。

### tab 武器程序（DataSendPageWeaponProgram）

- 4 行输入：主武器程序推荐、副武器程序推荐、PL-16主副武器选择允许、PL-13主副武器选择允许

- 15 行输入：PL-13导弹信息有效、PL-16导弹信息有效、PL-16攻击方式切换允许、
  PL-16AM攻击模式和弹道选择、PL-13AM攻击模式和弹道选择、PL-16目标RCS类型标志、
  PL-13目标RCS类型标志、PL-16目标尺寸类型标志、PL-13目标尺寸类型标志、

- 切换按钮：**开启DSU**（开启后文字变 **关闭DSU**，状态文字 **DSU 已开启！**）

## 各页「返回」按钮的定位规则

源码里返回按钮都在各页 `resizeEvent` 里重算，**没有固定像素坐标**。

**通用几何**（103/106/111/112/115/116/117/119）：

```
backW ≈ max(120, 区域宽 × 0.18)
backH = max(36, 区域高 × 0.06)
backX = (区域宽 - backW) / 2
backY = 区域高 - 边距 - backH
→ 区域底行居中
```

**例外**：

| 页 | 返回按钮位置 |
|---|---|
| 118 模型参数 | 「开启参数控制」与「返回」**并排底行居中**（等宽，中间 gap） |
| 113 ZMQ 汇聚 | **顶部行右侧**（与标题同行） |
| 104 条件测试 | **右上**（标题行右侧） |
| 108 / 109 | **没有返回按钮**（单向门） |
| 100 | 用「测试场景退出」 |
| 101 | 用「退出场景」（实测构建显示「退出测试」） |
| 102 | 用「退出\n自主空战」 |

> **标准定位法（UIA 修复后）**：`get_window_state` 读树后，
> 在各区域 `CViewArea.CMenuButton.m_btn_menu` 里按 `Name=返回` invoke；
> **多区域同名按 `CViewArea` 顺序选**。上面的几何公式只用于理解位置分布，**不需要算坐标**。

## 使用注意（与控件直接相关）

1. **菜单按钮 Name 就是中文文字，部分含换行**（首页布局按钮、`指定\n探测区域`、`退出\n自主空战`）
   → 按 Name 匹配时要考虑 `\n`
2. **灰按钮点了无效**（CUA 点 `disabled` 按钮不生效）；
   点条件后**等 1-2s 再断言按钮 enabled**（SS 镜像 ~1s）
3. **场景互斥**：任一场景 `state=2` 期间，其余三个场景菜单按钮被强制置灰
4. **页 104 的显示序号是 1-based，源码 case 下标是 0-based（差 1）** → 按按钮文字定位最稳
5. **切布局 = 全部区域与页面重建**，已开页面和 DSU 发送线程都会消失
